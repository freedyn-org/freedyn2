This installer contains freedyn2 together with a private Python and the components below.
Each keeps its own license; the license texts are installed with them (paths relative to the
installation directory). licenses\python-packages.txt lists every bundled Python package with
its version and license, generated from the packages' metadata when the installer was built.

Python runtime
--------------
Python 3.12 (CPython, build of python-build-standalone)
  Python Software Foundation License Version 2 (PSF-2.0).  licenses\Python-LICENSE.txt
  The Python build contains further libraries under their own permissive licenses (OpenSSL:
  Apache-2.0, zlib, libffi: MIT, SQLite: public domain, ...), listed in that file.

  Shared libraries (fdgen\bin\*.dll), linked dynamically: they may be replaced by other builds of
  the same libraries (sources: https://github.com/DrTimothyAldenDavis/SuiteSparse).

C compiler (component "C compiler", python\Lib\site-packages\ziglang)
--------------------------------------------------------------------
Zig (ziglang)                      MIT                ziglang\LICENSE
  Zig ships C libraries and headers for its targets under their own licenses: musl (MIT),
  MinGW-w64 (ZPL-2.1, parts public domain, BSD, LGPL), glibc headers (LGPL-2.1 and others),
  wasi-libc (Apache-2.0 WITH LLVM-exception, MIT), LLVM libc++, libc++abi, libunwind, libtsan

  COPYRIGHT, LICENSE*, and ziglang\lib\*\LICENSE.TXT. Model plugins compiled with it link only
  what the model needs.

The uninstaller removes the program; your data in %APPDATA%\freedyn2 and %LOCALAPPDATA%\freedyn2
(settings, caches of compiled model plugins) remains. Delete those directories to remove them.
