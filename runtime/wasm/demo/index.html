ai-first multibody dynamics.
    loading python and the solver ...

    Everything runs in this browser tab: the model is translated by freedyn2's Python generator in Pyodide and simulated by the freedyn2 runtime compiled to WebAssembly. Nothing is sent to a server. Library elements only (bodies, joints, springs, bushings, loads); expression forces and drivers need the desktop freedyn2.

    Your own model: open (or drop here) its YAML file with the meshes it reads (STL, OBJ), or one zip with all of them; paths in the YAML are relative to it. Meshes alone are added to the model in the editor.

    A link carries the model in the editor (link copies it): the part after # stays in your browser. Meshes are not in the link.
